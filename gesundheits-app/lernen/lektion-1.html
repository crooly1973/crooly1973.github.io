Wie funktioniert deine App unter der Haube?

Jede App – auch deine VITARA – besteht aus drei Bausteinen, die zusammenarbeiten. Stell dir vor, wir bauen ein Haus.

Die 3 Bausteine – wie beim Hausbau

🧱

HTMLDer Rohbau

Die Struktur: Wände, Räume, Türen. Beim Handy sind das die Texte, Knöpfe und Bilder – was da ist.

🎨

CSSDer Anstrich

Das Aussehen: Farben, Formen, Abstände. Also dein Türkis, die runden Ecken, die Schatten – wie es aussieht.

⚡

JavaScriptDie Technik

Das Verhalten: Lichtschalter, Klingel. Was passiert, wenn du tippst – was die App tut.

Ein echtes Beispiel aus deiner App

Der Häkchen-Knopf, mit dem du ein Präparat als „genommen" markierst. Probier ihn hier:

☀️
Vitamin D3 + K2
natural elements · 1 Tablette
↑ Tippe auf den Kreis rechts

Und so ist genau dieser Knopf aus den 3 Bausteinen gebaut:

🧱 HTML der Knopf selbst
<button class="check">
   <svg> ✓ </svg>   <!-- das Häkchen-Symbol -->
</button>
Das erzeugt einen Knopf. Das class="check" ist wie ein Namensschild – daran erkennen ihn CSS und JavaScript wieder. Innen steckt ein kleines Häkchen-Symbol.
🎨 CSS das Aussehen
.check {
   border-radius: 50%;      /* macht ihn rund */
   border: 2px solid grau;  /* dünner Rand */
   color: durchsichtig;   /* Häkchen unsichtbar */
}
.check.on {              /* wenn "an": */
   background: grün;      /* wird grün gefüllt */
   color: weiß;         /* Häkchen sichtbar */
}
Zwei Zustände: normal ist der Kreis leer mit Rand. Sobald er die Markierung on bekommt, wird er grün gefüllt und das Häkchen erscheint. CSS beschreibt nur, wie beides aussieht – noch passiert nichts von allein.
⚡ JavaScript das Verhalten
// "Wenn jemand auf den Knopf tippt ..."
knopf.addEventListener('click', () => {
   // ... schalte die Markierung 'on' um."
   knopf.classList.toggle('on');
});
Das bringt Leben rein. addEventListener('click', …) heißt „hör auf einen Tipp". toggle('on') ist ein Umschalter: ist die Markierung da, nimmt er sie weg – ist sie weg, setzt er sie. Genau deshalb wird der Kreis beim Antippen abwechselnd grün und wieder leer.

💡 Das Zusammenspiel

HTML stellt den Knopf hin, CSS macht ihn schön und definiert das grüne „an"-Aussehen, und JavaScript entscheidet beim Tippen, wann „an" gilt. Drei Bausteine, ein Ergebnis – und genau so ist deine ganze App aufgebaut, nur mit vielen solcher Teile.
